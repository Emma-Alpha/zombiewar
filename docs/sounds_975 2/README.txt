BOXHEAD - 2PLAY (僵尸危机3) extracted Flash sound resources

All files are the original MP3 audio embedded in the SWF.
Filenames correspond to the SWF sound IDs; sound_metadata.csv holds the audio details.

sound_usage.csv maps each file to its SWF linkage name and in-game use.
Files 539–564 have source linkage names. Files 174, 175, 184, 192 and 193
are embedded but have no source linkage/call site in this game SWF, so their
purpose is deliberately marked unknown rather than guessed.
