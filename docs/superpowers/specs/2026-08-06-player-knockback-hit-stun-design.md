# 玩家受僵尸攻击后的击退硬直设计

## 目标

僵尸近战攻击命中玩家时，玩家沿远离攻击来源的方向产生约“两步”的物理滑退。滑退会被世界碰撞阻挡，并在受击后的 1.2 秒内禁止武器攻击。

## 行为规则

- 只有实际扣除生命值的攻击才触发击退和武器锁定。
- 击退方向使用攻击来源到玩家的水平向量，不施加竖直冲量。
- 默认初始击退速度为 `8.0 m/s`，水平衰减为 `18.0 m/s²`。无遮挡时理论滑退距离约为 `1.78 m`，接近“两步”，约 `0.44 秒`停止。
- 击退通过玩家现有的 `CharacterBody3D.move_and_slide()` 执行，因此墙体和其他实体碰撞可使滑退提前结束，不直接修改玩家位置，也不穿墙。
- 击退速度尚未衰减完时忽略主动移动输入；击退结束后立即恢复移动控制。
- 武器攻击从受击时起锁定 `1.2 秒`。锁定开始时立即取消当前射击、连射或近战攻击；锁定期间持续向装备系统发送未按下攻击键的状态。
- 武器锁定不限制换枪和放置物品，避免扩大本次需求范围。
- 连续受击时，以最新攻击来源重新计算击退方向，并将武器锁定重新刷新为完整 `1.2 秒`。
- 玩家死亡时清除击退速度、受击动画计时和武器锁定计时。

## 代码设计

### `scripts/player/player_motion.gd`

增加无场景依赖的击退计算函数：

- 根据玩家位置、攻击来源位置和玩家朝向，计算水平击退方向。
- 当攻击来源与玩家位置重合时，使用玩家朝向的反方向作为安全回退。
- 根据当前击退速度、衰减值和帧时间计算下一帧的水平击退速度，且不发生反向运动。

这些纯函数便于对方向、距离趋势和边界输入进行稳定单元测试。

### `scripts/player/player_controller.gd`

增加可调参数：

- `hit_attack_lock_duration = 1.2`
- `hit_knockback_speed = 8.0`
- `hit_knockback_deceleration = 18.0`

增加运行时状态：

- 剩余武器锁定时间。
- 当前水平击退速度。

`apply_damage()` 在成功扣血后取消当前攻击、刷新锁定时间并设置击退速度。物理帧中如果仍有击退速度，则使用击退速度驱动水平移动并忽略主动移动；否则继续使用现有的玩家移动计算。重力、武器墙体净空检测和 `move_and_slide()` 仍沿用当前流程。

现有 `hit_reaction_remaining` 继续负责短暂的受击动画保护；武器是否允许攻击改为同时受短受击动画计时和 1.2 秒武器锁定计时约束。

## 异常与边界处理

- 伤害为零、生命值已耗尽或玩家已经死亡时，不产生新击退和锁定。
- 负数速度、衰减和时长按零处理，防止配置错误导致反向加速或永久锁定。
- 攻击来源位置缺失或与玩家重合时使用朝向回退，保证击退方向始终可用。
- 碰墙后 `move_and_slide()` 会裁剪实际速度；下一物理帧继续衰减剩余击退速度，玩家不会穿过障碍。

## 测试方案

### 单元测试

- 攻击来源位于玩家右侧时，击退方向朝左。
- 攻击来源与玩家重合时，使用玩家朝向的反方向。
- 击退速度按帧衰减且不会越过零点反向。
- 默认速度与衰减对应约 `1.78 m` 的无遮挡理论位移。

### 玩家场景测试

- 成功受伤后武器锁定计时为 `1.2 秒`，当前武器攻击被取消。
- 受伤后设置远离来源的水平击退速度。
- 锁定计时结束前攻击输入不会传递给武器，结束后可恢复攻击。
- 死亡会清除击退速度和武器锁定。

### 定向碰撞测试

- 增加玩家击退集成测试，在玩家身后放置静态墙体并触发受伤。
- 推进有限数量的物理帧，确认玩家朝远离攻击来源的方向移动，但不会穿过墙体。
- 新测试注册到 `tests/test_runner.gd`，验证时只运行本功能直接相关的测试文件。

### 验证命令

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --editor --path . --quit
./tests/run_tests.sh \
  tests/unit/test_player_motion.gd \
  tests/unit/test_player_damage.gd \
  tests/integration/test_player_knockback.gd
```

本功能不要求运行全量测试。视觉手感需要在游戏中人工确认：让僵尸从无遮挡方向命中玩家，观察滑退距离约为两步；再让玩家贴墙受击，确认滑退被墙体提前截停，并验证受击后约 1.2 秒内不能开火。
