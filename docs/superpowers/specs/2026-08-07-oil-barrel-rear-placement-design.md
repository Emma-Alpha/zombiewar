# 油桶身后放置设计

## 目标

玩家使用油桶装备时，油桶应放置在玩家当前瞄准方向的反方向，也就是玩家身后。其他可放置装备继续沿用默认的向前放置行为。

## 设计

在 `PlaceableEquipment` 中增加放置方向倍率配置，默认值为 `1.0`。装备请求放置物品时，将输入的瞄准方向乘以该倍率后再传给 `PlaceItemService`。

`OilBarrelEquipment.tscn` 将此倍率配置为 `-1.0`，从而只反转油桶的放置方向。网格选格、障碍检测、库存扣减和导航几何更新逻辑保持不变。

## 边界行为

- 输入方向无效时，反转后仍为无效方向，由现有放置服务拒绝。
- 身后目标格被占用或存在动态障碍时，沿用现有拒绝逻辑，不尝试其他格子。
- 油桶放置失败时不扣减数量。
- 未来新增的可放置装备默认仍放在前方，除非场景显式修改方向倍率。

## 验证

- 添加最小验证，确认默认配置将原始瞄准方向传给放置服务。
- 添加最小验证，确认油桶配置将反向瞄准方向传给放置服务。
- 运行 Godot headless editor 检查场景与脚本解析。
- 游戏内装备油桶并朝任意方向放置，确认油桶出现在角色身后一格；身后被占用时应拒绝放置且不扣数量。
