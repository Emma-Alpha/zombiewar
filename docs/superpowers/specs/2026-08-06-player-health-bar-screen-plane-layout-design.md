# 玩家血条屏幕平面缩减设计

## 目标

修正玩家头顶血条在扣血后的“双条”观感与居中缩短问题。血条必须在任何玩家朝向下都以屏幕左端为固定锚点，从右端缩短；完整深色轨道只表示空血部分，不能被误读为第二条血条。

本轮只重做 `HealthBar3D` 的坐标与图层组织，不改变玩家生命值、伤害、死亡、颜色阈值、僵尸、武器或 HUD 范围。

## 根因

现有 `Background` 与 `Fill` 分别由 shader billboard 到相机，但 `Fill.position.x` 和曾经的局部 Z 偏移仍经过玩家父节点的旋转。玩家转身后，填充条的位置在世界空间旋转，而面片方向保持相机方向，因此“左端固定”的计算不再处于同一坐标系，表现为填充居中、漂移或与背景分离。

此外，完整宽度的深色背景使用较高不透明度，会在短彩色填充旁呈现为一条独立的黑色血条。

## 方案选择

采用单一“相机平面根节点”方案：`HealthBar3D` 自己取得父 `Node3D` 与活动 `Camera3D`，每帧在父节点头顶同步世界位置，并把自己的朝向完全对齐相机。`Background` 和 `Fill` 回归普通子面片；它们共享根节点的相机平面，不能各自再处理 billboard shader 矩阵。

不在 shader 内换算填充的局部偏移。该方案需要把角色局部坐标换算为相机平面坐标，容易再次引入朝向相关错误。

不改为屏幕 HUD 投影。该方案会将单个单位组件耦合到 HUD 与相机管理器，不符合当前可复用场景的边界。

## 组件与数据流

`HealthBar3D` 仍作为玩家的子节点，但在 `_ready()` 后设为 top-level 世界节点：

1. 缓存父 `Node3D` 作为跟随目标。
2. 通过当前视口获取活动 `Camera3D`。
3. 每帧将 `global_position` 设置为 `follow_target.global_position + anchor_offset`。
4. 使用活动相机的全局朝向作为 `global_basis`，使组件局部 X 轴始终等同于屏幕水平轴。

玩家场景将头顶偏移改为组件的 `anchor_offset = Vector3(0, 2.35, 0)` 配置。血条根节点不再依赖玩家节点的局部 `position` 或 `rotation`。

在统一相机平面内，填充规则为：

- 背景轨道宽度恒为 `1.10m`、高度为 `0.10m`。
- `Fill.scale.x = ratio`。
- `Fill.position.x = -0.55 + 0.55 * ratio`。
- 因此填充左边缘恒为 `-0.55`，只会移动右边缘。
- `ratio == 0.0` 时隐藏填充；背景轨道继续显示。

现有血量接口和逻辑保持不变：`set_health(current, maximum, animate)` 仍在 `0.20` 秒内平滑宽度；每次更新替换旧 Tween；颜色在真实比例大于 `60%`、`30%–60%`、低于 `30%` 时分别为绿、黄、红。

## 渲染规则

- `Background` 与 `Fill` 使用无光照、透明、关闭深度检测的圆角材质，但不再包含 `MODELVIEW_MATRIX` billboard 顶点逻辑。
- `Fill` 的材质渲染优先级高于 `Background`；两个节点没有局部 Z 偏移。
- `Background` 的 alpha 降为约 `0.35`，颜色保持中性深色；它只表达未填充区，不应像第二条实心血条。
- `Fill` 保持实心绿、黄、红色；不增加延迟残血条、数字、刻度或描边。

## 容错

- 找不到父 `Node3D` 或活动 `Camera3D` 时，组件保留最近一次有效变换，只记录一次警告；不得影响玩家的伤害、武器、死亡或生命信号。
- 组件进入树时先执行一次同步，避免首帧使用无效变换。
- 父节点被移除或不在树中时停止同步，不能访问失效对象。

## 测试与人工验收

新增核心回归测试：

- 组件同步到模拟父节点的头顶位置，并采用相机 basis。
- 模拟玩家 Y 轴为 `0°` 与 `180°` 时，填充左端在组件局部相机平面内都为 `-0.55`。
- 背景与填充不再含 billboard 顶点矩阵；填充优先级高于背景；背景 alpha 为 `0.35`。
- 连续 `set_health()` 更新仍只保留一个 Tween，且 0 血时仅隐藏 `Fill`。

运行无头编辑器导入检查与现有测试运行器。当前已知 4 项刀具配置失败不在本轮修复范围；新增或既有血条测试不得失败。

人工验收：启动 Demo，让僵尸造成伤害后在玩家转向 `0°`、`90°`、`180°` 时观察。彩色部分必须始终从屏幕左侧固定处向右缩短；背景仅为淡色空轨道，不能被感知为第二条血条。

## 非目标

- 延迟受伤残血条、治疗动画、数字文本、描边或新的 HUD。
- 僵尸接入血条或修改僵尸数值标签。
- 修改玩家生命、伤害、死亡、攻击、AI、武器或刀具配置。
