# 冲锋枪迁移与散弹枪设计

## 目标

将现有步枪完整迁移为冲锋枪，保留现有射速、伤害、弹药和散布数值；同时新增一把通过武器箱获取的有限弹药散弹枪。散弹枪每轮发出三条带固定夹角的即时命中弹道，近距离三颗全中时爆发高，远距离只能命中部分弹丸时效率明显下降。

## 范围

- 原 `rifle` 武器完整迁移为 `smg`，包括显示名、稳定 ID、资源、场景、模型节点、拾取物、Demo 配置、验证脚本和 README。
- 冲锋枪保留现有数值：每秒 `4` 发、单发 `25` 伤害、弹药上限 `360`，其余射程、散布、后坐与镜头反馈维持当前资源默认值。
- 新增散弹枪、散弹武器箱和散弹弹药箱。
- Demo 固定放置两个新拾取点，并把两种散弹拾取物加入随机掉落池。
- 不增加换弹、弹匣、实体弹丸、穿透或新输入方式。

## 架构

继续使用现有 `RangedWeapon` hitscan 架构，不创建散弹枪专用攻击脚本。`RangedWeaponDefinition` 增加每轮弹丸数和相邻弹道夹角配置；新的纯计算单元 `WeaponVolleyMath` 根据中央方向生成对称弹道数组。手枪和冲锋枪使用默认单弹丸配置，散弹枪配置三弹丸。

每轮攻击只执行一次触发门判断和一次弹药消耗。`RangedWeapon` 先通过现有 `WeaponSpreadState` 解析本轮中央方向，再围绕世界竖直轴应用固定角度偏转。三条弹道分别执行现有射线命中解析、伤害和曳光反馈；枪口火焰、音效、后坐、镜头冲击和 `attack_resolved` 信号仍只执行一次。

## 多弹丸规则

- 散弹枪每轮弹丸数：`3`。
- 相邻弹道夹角：`6°`。
- 三条弹道相对中央方向为：`-6° / 0° / +6°`。
- 散弹枪自身随机散布全部设为 `0°`，保证扇形稳定可读。
- 同一目标允许被同一轮中的多颗弹丸分别命中。
- 每条弹道只伤害遇到的第一个目标，继续使用 `max_penetration_count = 0`。
- 每颗弹丸独立生成一条曳光，并在自己的首次碰撞位置结束。
- 对外汇总结果累加三颗弹丸实际造成的伤害；方向使用中央弹道。

## 散弹枪数值

| 配置 | 数值 |
| --- | ---: |
| 触发方式 | 按住连续射击 |
| 每轮间隔 | `0.8s` |
| 每秒轮数 | `1.25` |
| 每颗伤害 | `25` |
| 三颗全中理论伤害 | `75` |
| 射程 | `18m` |
| 弹药上限 | `120` |
| 武器箱授予 | `24` 发并自动装备 |
| 弹药箱补充 | `36` 发 |

每轮三颗弹丸只消耗 `1` 发散弹。当前普通僵尸为 `50 HP`，因此近距离三颗全中可以一轮击杀；远距离若只命中一颗，则需要第二轮。

## 装备与模型

玩家装备顺序调整为：手枪、冲锋枪、散弹枪、匕首、油桶。冲锋枪和散弹枪默认未拥有，必须通过对应武器箱获得。两个场景分别绑定角色模型中的 `SMG` 与 `Shotgun` 节点，并继续使用统一远程武器墙体包络、枪口起点和抬枪规则。

## 拾取与 Demo

- 冲锋枪拾取沿用原步枪拾取数值：武器箱 `+60`，弹药箱 `+90`，弹药上限 `360`。
- 散弹武器箱使用 `item_id = &"shotgun"`、`amount = 24`、`auto_equip = true`。
- 散弹弹药箱使用 `item_id = &"shotgun"`、`amount = 36`、`auto_equip = false`。
- Demo 保留现有冲锋枪、冲锋枪弹药和油桶固定拾取点，并新增散弹枪与散弹弹药固定拾取点。
- Demo 随机掉落池包含冲锋枪武器、冲锋枪弹药、散弹枪武器、散弹枪弹药和油桶五种定义。

## 失败与兼容行为

- 不保留旧 `rifle` ID 或旧资源入口；所有运行时、README 与验证引用必须一次性迁移为 `smg`。历史设计文档保留当时语境，不纳入迁移扫描。
- 未拥有散弹枪时，散弹弹药箱领取失败且不被消耗。
- 散弹枪弹药为零时，不生成射线、曳光、音效或射击信号。
- 多弹丸配置无效时由资源范围限制收敛：弹丸数最少为 `1`，夹角最小为 `0°`。
- 三条射线中的任意一条被墙体阻挡时，只结束该条射线，不影响同轮其他射线继续解析。

## 验证

自动验证覆盖：

- `WeaponVolleyMath` 对单弹丸和三弹丸生成正确、归一化、水平且对称的方向。
- 手枪、冲锋枪和散弹枪资源的弹丸配置与数值契约。
- 散弹枪默认未拥有、武器箱授予 `24` 发并自动装备、弹药上限为 `120`、弹药箱补充 `36` 发。
- 玩家装备顺序和 `smg` 稳定 ID 迁移完成，仓库运行时文件不再引用 `rifle`。
- Demo 五个固定拾取点及五项随机掉落池配置正确。
- 现有装备、拾取、多人输入和远程武器碰撞掩码验证无回归。
- Godot headless editor 导入和 DemoArena headless Smoke Test 通过。

人工验收覆盖：

1. 拾取散弹武器箱后自动装备并显示 `24` 发。
2. 按住攻击键以约 `0.8s` 间隔连续开火，每轮弹药只减少 `1`。
3. 近距离对准普通僵尸时三条曳光可共同命中并一轮击杀。
4. 拉远距离后观察三条固定扇形弹道，单目标通常只吃到部分伤害。
5. 三个并排或狭窄通道内的目标可被同一轮不同弹道分别命中。
6. 墙体分别截断对应弹道，墙后目标不受伤。
7. 冲锋枪显示、模型、拾取、弹药和每秒 `4` 发行为与原步枪一致。
