# 爆炸油桶设计

## 目标

在 DemoArena 中加入可被枪械和爆炸触发的油桶。任意枪械需要命中三次才能引爆；第二次命中后必须出现明显、持续的破损表现。油桶爆炸会按距离伤害玩家和僵尸，并可以引爆其他油桶，形成伤害可叠加的连锁爆炸。

本功能同时建立可供后续手雷、火箭等爆炸来源复用的范围伤害解析能力。近战、僵尸攻击、普通碰撞和非爆炸环境伤害不得破坏油桶。

## 已确认行为

- 任意枪械每次有效射击对油桶累计一次命中，不使用武器伤害值计算耐久。
- 第一次枪械命中只播放短暂金属命中反馈。
- 第二次枪械命中进入持续破损状态，油桶轮廓发生明显变化，并持续冒黑烟和橙色火星。
- 第三次枪械命中立即引爆油桶。
- 明确标记为爆炸伤害的来源可以立即引爆油桶，包括其他油桶、后续手雷和后续火箭。
- 小刀等近战攻击、僵尸攻击和普通物理碰撞不能累计命中或触发油桶。
- 爆炸会伤害玩家和僵尸。
- 世界墙体、车辆和集装箱等第一层静态碰撞完全阻挡爆炸伤害。
- 一次爆炸内，同一目标即使拥有多个碰撞体也只结算一次伤害。
- 不同爆炸分别结算；多个油桶连锁命中同一目标时，伤害正常叠加。
- 油桶只能爆炸一次，重复伤害或异步连锁回调不能再次生成伤害与特效。

## 方案选择

采用“独立爆炸解析器 + 独立油桶状态 + 纯视觉爆炸特效”的拆分方案。

不把范围查询、距离衰减和遮挡检测全部写入油桶脚本，因为后续手雷和火箭需要复用这些规则。也不使用常驻爆炸 `Area3D` 监控范围；爆炸是瞬时事件，发生时执行一次物理形状查询更直接，并且更容易保证目标去重和遮挡检测的一致性。

## 总体架构

### `ExplosiveBarrel`

油桶场景根节点使用 `StaticBody3D`，保持世界碰撞层 1，使玩家、僵尸、枪械射线和武器贴墙逻辑都把它视为世界障碍。

油桶不加入 `damageable_targets`，也不提供供近战查询的伤害 `Area3D`。现有近战只查询 `damageable_targets` 的区域，因此无法命中油桶。

油桶提供两个明确入口：

- `apply_hit(amount, hit_position, shot_direction)`：保持与现有枪械射线调用约定兼容。忽略武器伤害数值，每次调用只累计一次枪械命中。
- `apply_explosion_damage(amount, origin)`：供统一爆炸解析器调用。只要收到正数爆炸伤害，就进入连锁引爆流程，不累计枪械命中次数。

油桶状态至少包括：

- `INTACT`：0～1 次枪械命中。
- `DAMAGED`：2 次枪械命中，启用持续破损表现。
- `EXPLODING`：已经接受引爆，禁止任何重复触发。
- `DESTROYED`：碰撞已关闭、伤害已结算，等待视觉清理完成。

第三枪直接引爆；爆炸触发则不受当前枪械命中次数影响。状态切换必须是幂等的。

### `ExplosionResolver`

爆炸解析器是无持久场景状态的共享逻辑，接收以下爆炸参数：

- 世界上下文。
- 爆炸中心。
- 半径。
- 中心伤害和边缘伤害。
- 目标碰撞掩码。
- 世界遮挡掩码。
- 来源对象或需要排除的 RID。
- 是否允许触发其他爆炸物。

解析器使用球形物理查询收集玩家、僵尸和油桶候选对象。候选对象先解析到唯一伤害接收根节点，再按实例 ID 去重。每个目标分别执行距离衰减和遮挡射线：

- 射线未命中世界碰撞时，目标可受伤。
- 第一个世界碰撞属于目标自身时，目标可受伤。
- 第一个世界碰撞是其他墙体、车辆、集装箱或油桶时，目标被遮挡，不受该次爆炸伤害。

玩家使用 `apply_damage()`，僵尸使用 `apply_hit()`，油桶使用 `apply_explosion_damage()`。解析器不得依赖 DemoArena，也不得生成视觉或声音。

距离伤害采用线性衰减：爆炸中心为中心伤害，半径边缘为边缘伤害，范围外不结算。每个爆炸调用维护独立去重集合，因此不同爆炸对同一目标的伤害可以正常叠加。

### `BarrelExplosion`

爆炸特效场景放在 `scenes/fx/`，只负责视觉和音频：

- 快速火球与闪光。
- 向外扩散的烟雾和火星。
- 短暂点光。
- 使用现有重型金属声音并降低音调，作为首版临时爆炸音效。
- 有限生命周期结束后自动释放。

场景根脚本实现：

- `warmup_for_render(context)`
- `finish_render_warmup()`

预热只激活视觉渲染，不播放音频、不执行范围伤害、不引爆真实油桶。

### 破损表现

当前资源没有专用的破损油桶模型。第二次枪械命中后采用组合表现：

- 油桶模型持续轻微压扁并倾斜，改变轮廓。
- 启用低强度黑烟。
- 间歇发射橙色火星。
- 保持碰撞不变，第三枪前仍是完整障碍。

破损视觉与命中计数解耦。未来替换专用破损模型时，不修改伤害与爆炸逻辑。

## 爆炸参数

首版采用以下固定默认值，并通过导出属性保留场景调参能力：

- 爆炸半径：4.5 米。
- 中心伤害：80。
- 边缘伤害：20。
- 距离衰减：线性。
- 油桶枪械命中次数：3。
- 进入破损状态的枪械命中次数：2。
- 连锁引爆延迟：0.12 秒。

连锁延迟用于让多个油桶的爆炸顺序可读。油桶在接受连锁触发时立即锁定为 `EXPLODING`，延迟期间不能再次排入引爆队列。

## 场景与导航集成

将 `Barrel.gltf` 及其贴图从原型资源目录复制到正式运行时 `assets/environment/`。新增 `scenes/props/ExplosiveBarrel.tscn`，并在 DemoArena 西侧放置三个实例：

- 两个油桶之间的距离小于爆炸半径，用于展示连锁爆炸。
- 第三个油桶与前两个保持超过爆炸半径的距离，用于独立射击验证。

油桶碰撞加入 `navigation_source`，让运行时导航把完整油桶作为静态障碍。引爆顺序为：

1. 将状态锁定为 `EXPLODING`。
2. 关闭油桶碰撞并停止破损烟雾。
3. 延迟到碰撞状态真正生效后，通知 DemoArena 标记 `demo_arena` 导航区块为脏。
4. 生成爆炸视觉并执行范围伤害。
5. 删除油桶本体。

DemoArena 负责连接油桶的导航几何变化信号，并调用场景级 `NavigationWorldManager.mark_chunk_dirty()`。油桶自身不查找全局管理器，避免破坏场景级导航所有权边界。

## 枪械、近战与未来爆炸来源

现有枪械射线在命中非 `damageable_targets` 世界碰撞时，仍会尝试调用碰撞对象的 `apply_hit()`，随后停止射线。因此油桶可以接收枪械命中，同时不会进入僵尸穿透计数。

现有近战只查询 `damageable_targets` 区域，而且不查询世界刚体。油桶不属于该分组，也没有伤害区域，因此近战无法影响油桶。

后续手雷和火箭只负责确定爆炸发生时机，然后调用 `ExplosionResolver`。只要请求允许触发爆炸物，解析器就会调用油桶的 `apply_explosion_damage()`，无需复制油桶连锁逻辑。

## 错误与边界处理

- 油桶离开场景树或已经排队释放后，延迟连锁回调必须安全退出。
- 重复枪械射线、多个爆炸同帧命中或爆炸查询重复碰撞体不能重复引爆同一个油桶。
- 爆炸目标没有有效受伤方法时直接忽略，不报告玩法错误。
- 世界或物理空间不可用时，油桶仍播放爆炸视觉并完成清理，但不执行范围伤害。
- 导航管理器或区块不存在时记录警告，不阻止油桶完成爆炸。
- 单个特效预热失败不能阻止 DemoArena 进入游戏。

## 测试策略

本功能属于中等风险玩法功能，测试覆盖核心伤害规则、范围查询和场景契约，不追求视觉像素级自动验证。

### 单元测试

- 线性伤害衰减在中心、半径中点、边缘和范围外返回正确结果。
- 油桶第一次枪械命中保持完整，第二次进入破损状态，第三次只触发一次爆炸。
- 正数爆炸伤害直接锁定并触发油桶，不需要三次枪械命中。
- 已进入 `EXPLODING` 或 `DESTROYED` 的油桶忽略后续枪械与爆炸伤害。
- 不同爆炸调用不共享去重状态。

### 集成与场景契约测试

- 枪械射线能够命中油桶并累计一次，射线停止在油桶位置。
- 小刀攻击不会累计油桶命中次数。
- 单次爆炸对拥有多个碰撞体的目标只结算一次。
- 两次独立爆炸对同一目标累计两次伤害。
- 玩家和僵尸根据距离受到衰减伤害。
- 世界碰撞体阻挡玩家、僵尸和油桶受到爆炸伤害。
- 一个油桶的爆炸能够延迟触发另一个油桶。
- 油桶碰撞关闭后，DemoArena 导航区块被标脏。
- DemoArena 包含三个油桶，两个可连锁、一个独立。
- `BarrelExplosion` 和破损烟雾特效实现统一 FX 预热协议，预热结束后恢复非活动状态。

### 自动验证

- `/Applications/Godot.app/Contents/MacOS/Godot --headless --editor --path . --quit`
- `./tests/run_tests.sh`

### 人工验收

1. 用手枪射击同一油桶三次，确认第二枪后持续冒烟并明显变形，第三枪爆炸。
2. 用步枪重复验证，确认同样需要三枪。
3. 用小刀攻击油桶，确认油桶没有破损或命中累计。
4. 引爆相邻油桶，确认约 0.12 秒后发生连锁爆炸。
5. 玩家同时处于两次爆炸范围内，确认两次伤害叠加。
6. 玩家躲在车辆或集装箱后引爆油桶，确认掩体阻挡爆炸伤害。
7. 引导僵尸经过油桶区域，销毁油桶后确认导航重烘焙完成，僵尸能够使用释放出的空间。
8. Web 导出环境连续触发三个油桶，确认没有明显首次特效冻结或碎片造成的性能问题。

## 非目标

- 物理碎片和可交互残骸。
- 持续燃烧地面或持续火焰伤害。
- 油桶掉落物、资源奖励或任务事件。
- 专用破损模型和专用爆炸音频资产。
- 手雷投掷、引信和弹道实现。
- 火箭武器实现。
- 爆炸对未来可破坏墙体的具体材质伤害规则。
