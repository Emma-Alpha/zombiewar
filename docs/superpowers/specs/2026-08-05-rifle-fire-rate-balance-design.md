# 步枪射速平衡设计

## 背景

当前步枪以每秒 `6` 发持续射击，每发造成 `25` 点伤害。玩家认为连发节奏过快，希望降低射速，使射击反馈更沉稳、接近预期中的真实枪械节奏。

## 已确认方案

- 将步枪射速从每秒 `6` 发调整为每秒 `4` 发，射击间隔由约 `0.167` 秒增加到 `0.25` 秒。
- 步枪单发伤害保持 `25` 点不变。
- 保持连发触发方式、射程、散布、后坐、镜头冲击、声音、弹道池和碰撞判定不变。

## 平衡结果

- 步枪理论持续输出从 `150 DPS` 降为 `100 DPS`。
- 当前普通僵尸生命值为 `50`，身体命中仍需两发击杀；两发之间的最短间隔从约 `0.167` 秒增加到 `0.25` 秒。
- 手枪保持每秒最多 `3` 发、每发 `35` 点伤害。步枪的理论 DPS 会略低于手枪，但步枪仍保留按住连续射击、较远射程和自动攻击的操作优势。

## 修改范围

- `resources/weapons/rifle.tres`：把 `attacks_per_second` 改为 `4.0`，保留 `damage = 25.0`。
- `tests/unit/test_weapon_configuration.gd`：把步枪射速契约更新为 `4.0`，并明确验证步枪伤害仍为 `25.0`。
- `README.md`：把操作说明中的步枪射速更新为每秒 `4` 发。

## 验证

- 运行自定义测试套件，确认武器配置与射速门行为通过。
- 运行 Godot 无头编辑器检查资源与脚本解析。
- 人工验收时按住攻击键，确认步枪约每 `0.25` 秒开火一次，普通僵尸仍需两枪击杀。
