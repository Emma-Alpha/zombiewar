# 补给箱字体与模型缩小设计

## 目标

统一缩小所有 `PickupChest` 实例的箱体模型和悬浮奖励文字，包括 Demo 固定补给点与僵尸死亡随机掉落。

## 视觉调整

- `Chest.gltf` 可视模型统一缩放到当前尺寸的 `75%`。
- 补给悬浮文字使用 `font_size = 64`、`pixel_size = 0.005`、`outline_size = 6`。
- 玩家装备文字使用 `font_size = 64`、`pixel_size = 0.006`、`outline_size = 6`。
- 两类 `Label3D` 关闭 `fixed_size`，以高分辨率字形按正交相机下的世界尺寸渲染，避免低分辨率字形被强制放大。
- 文字高度从 `1.35` 调整为 `1.25`，仍位于缩小后的箱体与信标上方，且不发生重叠。

## 物理与交互

- 箱体实体碰撞尺寸和高度随模型同步缩小，避免不可见的大碰撞体。
- `ClaimArea` 拾取触发范围保持当前尺寸，避免补给箱缩小后变得难以领取。
- 发光圆环与信标保持当前尺寸和颜色逻辑，确保小模型仍容易发现。
- 不修改奖励 Definition、刷新时间、一次性回收或多人归属逻辑。

## 验证

- 运行 Godot headless editor 导入检查，确认场景无解析错误。
- 运行 `validate_pickup_spawn_point.gd` 与 `validate_random_pickup_drops.gd`，确认固定补给和随机掉落生命周期未回归。
- 游戏内检查固定补给与随机掉落的文字比例、箱体碰撞和拾取距离。
